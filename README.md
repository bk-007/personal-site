# brycek.me

A deliberately tiny personal site.

The experience is simple: hello, welcome, goodbye, then the page dissolves away. Seasonal themes follow the calendar automatically and can also be selected manually from the `brycek.me` menu.

## Development

```sh
pnpm install
pnpm run dev
```

Production build:

```sh
pnpm run build
```

The site is built with static HTML/CSS/JavaScript, Vite, and Cloudflare tooling.
